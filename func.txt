1. TỔNG QUAN HỆ THỐNG
────────────────────────────────────────────────────────────────────────────────

Nền tảng học toán qua game cho học sinh (lớp/khối → chủ đề → bài học → câu hỏi).
Người dùng chơi game, làm đề thi, thi đấu cuộc thi, tích điểm, mua vật phẩm.
Admin quản lý nội dung, người dùng, đề thi, cuộc thi, cửa hàng.

Kiến trúc:
  • User API     → /api/*           (server.js)
  • Admin API    → /api/admin/*     (server-admin.js, yêu cầu JWT + role admin)
  • Ảnh tĩnh     → /questions-images, /items-images, /types-images,
                   /lessons-images, /grades-images, /music

Xác thực:
  • Header: Authorization: Bearer <JWT>
  • role = 1 → admin
  • POST /api/login, POST /api/register, GET /api/auth/me
  • Tích hợp Kilovia: POST /api/external-login-child (maTreEm)

2. CẤU TRÚC CÂU HỎI (answers_json — hệ thống mới)
────────────────────────────────────────────────────────────────────────────────

Lưu trữ: một cột DB `answers_json` (không còn cột legacy answer1..4).

API trả về mảng answers[]:
  { id, text, image, correct }

Giới hạn (backend/lib/questionAnswers.js):
  • Tối đa 3 đáp án ĐÚNG  (MAX_CORRECT_ANSWERS = 3)
  • Tối đa 3 đáp án SAI   (MAX_WRONG_ANSWERS = 3)
  • Tổng tối đa 6 đáp án

Chấm điểm (full_set — frontend/src/users/lib/questionScoring.js):
  • isAnswerSetFullyCorrect(question, selectedIds)
  • Đúng khi chọn ĐỦ và CHỈ các đáp án có correct=true
  • Áp dụng: game1–11, đề thi, cuộc thi (QuestionAnswerPicker)

Scope play (GET /api/questions?scope=play):
  • Payload nhẹ: id, question_text, question_image, answers[] (không lộ correct cho client? — 
    thực tế answers vẫn có trường correct; game dùng phía client để chấm)
  • Dùng khi load câu hỏi cho game/bài học

6. CHỨC NĂNG THEO MODULE

[Xác thực & tài khoản]
  • Đăng ký / đăng nhập / phiên JWT
  • Kilovia external-login-child (tự tạo user kid_<maTreEm>)

  • Mẫu đề (exam_templates) + gán câu hỏi

  • Tự phát thưởng top 3 khi cuộc thi kết thúc (prize → users.score)

[Cửa hàng & vật phẩm]
  • Mua bằng điểm (require_score)
  • Hiệu ứng: bonus điểm bài học, gợi ý câu hỏi (item-effects)

[Bảng xếp hạng]
  • /api/leaderboard/all — tổng điểm
  • /api/leaderboard/week — điểm tuần (tự reset sang tuần mới)

[Admin]
  • Dashboard + performance
  • CRUD users, grades, types, lessons, questions, exam-templates, contests, items
  • Upload ảnh khối/chủ đề/bài/câu hỏi/vật phẩm

7. API NGƯỜI DÙNG — server.js
────────────────────────────────────────────────────────────────────────────────

Auth không cần token trừ khi ghi (auth):
  (none)  = công khai
  (auth)  = Bearer JWT
  (admin) = Bearer JWT + role admin

─── XÁC THỰC ───────────────────────────────────────────────────────────────

POST   /api/register                    (none)
       Body: { username, password, email?, phone? }
       → Tạo tài khoản mới

POST   /api/login                       (none)
       Body: { username, password }
       → { user, token }

GET    /api/auth/me                     (auth)
       → User hiện tại từ DB

POST   /api/external-login-child        (none)
       Body: { maTreEm, fullname?, school? }
       → Kilovia SSO: tìm/tạo user, trả token

─── PHÂN CẤP NỘI DUNG ───────────────────────────────────────────────────────

GET    /api/grades                      (none)
       → Danh sách khối/lớp { id, name, image }

GET    /api/hierarchy-labels            (none)
       → Nhãn UI phân cấp (grade/type/lesson labels)

GET    /api/types/:grade_id             (none)
       → Chủ đề theo khối

GET    /api/lessons/:type_id            (none)
GET    /api/operations/:type_id         (none)  — alias cùng handler
       → Bài học theo chủ đề

─── CÂU HỎI ────────────────────────────────────────────────────────────────

GET    /api/questions                   (none)
       Query: grade_id, type_id, lesson_id | operation_id,
              limit, offset, random=0|1, search, scope=play
       • scope=play → payload game (nhẹ)
       • không scope → list admin-style (hierarchy_path, in_exam_template)
       → { count, total, data[] }

GET    /api/questions/:id/usage         (admin)
       → Câu hỏi đang dùng trong mẫu đề nào

GET    /api/questions/:id               (none)
       → Chi tiết 1 câu (answers[])

POST   /api/questions                   (admin)
       Body: JSON hoặc multipart (question_image)
       • grade_id, type_id, lesson_id, question_text
       • answers[] hoặc answers_json — tối đa 3 đúng + 3 sai
       → Tạo câu hỏi

PUT    /api/questions/:id               (admin)
       Body: tương tự POST
       → Cập nhật câu hỏi

DELETE /api/questions/:id               (admin)
       → Xóa câu hỏi

─── TIẾN ĐỘ BÀI HỌC ──────────────────────────────────────────────────────

GET    /api/lesson-progress/completed   (auth)
       → Danh sách bài đã hoàn thành

GET    /api/lesson-progress/last        (auth)
       → Bài học làm gần nhất

GET    /api/lesson-progress             (auth)
       Query: lessonId?
       → Tiến độ theo bài hoặc tất cả

POST   /api/lesson-progress             (auth)
       Body: { lessonId, gradeId, typeId, correctCount, totalCount, gameId? }
       → Lưu sao / số câu đúng sau session game

─── ĐIỂM & HỒ SƠ ───────────────────────────────────────────────────────────

POST   /api/score/increment             (auth)
       Body: { userId?, delta=1 }
       → Cộng score + week_score (admin có thể chỉ userId khác)

GET    /api/user/:username              (auth — self hoặc admin)
       → Hồ sơ đầy đủ + rank tuần

─── BẢNG XẾP HẠNG ──────────────────────────────────────────────────────────

GET    /api/leaderboard/all             (none)
       → Top điểm tổng

GET    /api/leaderboard/week            (none)
       → Top điểm tuần

─── ĐỀ THI (exam_templates — phía user) ────────────────────────────────────

GET    /api/exams                       (auth)
       Query: grade_id?, page, page_size
       → Danh sách đề đang active (status=1), phân trang

GET    /api/exams/:id                   (auth)
       → Chi tiết đề + questions[] (answers[])

─── CUỘC THI ────────────────────────────────────────────────────────────────

GET    /api/contests                    (auth)
       → Danh sách cuộc thi (trạng thái theo thời gian)

GET    /api/contests/:id                (auth)
       → Chi tiết + câu hỏi từ template

GET    /api/contests/:id/leaderboard    (auth)
       → BXH cuộc thi

POST   /api/contests/:id/submit         (auth)
       Body: { score, times }  — times = giây làm bài
       → Nộp kết quả (1 lần/user/contest)

─── CỬA HÀNG ────────────────────────────────────────────────────────────────

GET    /api/items                       (none)
       → Danh sách vật phẩm

GET    /api/item-effects                (auth)
       → Hiệu ứng vật phẩm user đang có

POST   /api/buy                         (auth)
       Body: { itemId }
       → Mua vật phẩm bằng điểm

GET    /api/my-items/:userId            (auth)
       → Vật phẩm của user
